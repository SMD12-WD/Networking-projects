# Cisco Packet Tracer Projects
This section contains my hands on Cisco Packet Tracer projects and networking labs developed while building practical networking and cybersecurity skills.

The projects simulate real world network environments, ranging from small office networks to multi-VLAN infrastructures. Each project focuses on designing, configuring, testing, and troubleshooting network devices and services using Cisco IOS and Packet Tracer.

## Areas Covered

- VLAN configuration and network segmentation
- Inter-VLAN routing
- IP addressing and subnetting
- DHCP configuration and DHCP relay
- DNS configuration
- Wireless networking and WAP configuration
- Network device configuration
- Network services
- Email server configuration
- FTP server configuration
- Network troubleshooting and connectivity testing
- Basic network security configurations

## Network Services

Several projects include simulated network services such as:

- DHCP – Dynamic IP address assignment
- DNS – Hostname resolution
- Email – SMTP/POP3 email communication
- FTP – File transfer services
- HTTP/HTTPS – Web services

## Security & Administration

As I progress through my networking and cybersecurity studies, I am also implementing security-focused configurations including:

- SSH secure remote management
- VLAN-based network segmentation
- Switch security
- Access control
- Network hardening
- Secure management practices

## Objective

The goal of these projects is to develop practical experience designing, configuring, securing, and troubleshooting computer networks while building a strong foundation in Cisco networking and cybersecurity.

I will continue adding projects and expanding the complexity of these labs as I develop my networking and security skills.
